git clone - Копирует существующий репозиторий на пк вместе с историей.
git status - Показывает состояние папки: изменённые, подготовленные и новые файлы.
git add - Добавляет файл.
git commit Сохраняет подготовленные изменения в истории репозитория.
git push - Отправляет локальные коммиты в удалённый репозиторий.
git log - Показывает историю коммитов.
git branch - Показывает существующие ветки.
git switch - Переключает на указанную ветку.
git merge - Объединяет изменения указанной ветки с текущей.
git init - Создаёт новый гит-репозиторий.
